YouTubeショートをオフライン保存する方法：形式・画面比率と正しい活用ガイド

縦長で尺の短いYouTubeショートは、後から見失いやすいコンテンツです。用途に合ったファイル形式の選び方、リンクのコピー方法、必要なストレージ容量の目安に加え、法令や制作者の権利を尊重した安全な扱い方を解説します。

YouTubeショートは縦型の短尺動画であり、多くの人が慣れ親しんできた横長動画とは異なる特性を持っています。スマートフォンを縦に持った状態で視聴するよう設計されており、ループ再生されるうえ、わずか数秒で終わるものも少なくありません。そのため気軽に視聴できる反面、手元に保存したり編集したり、あるいはテレビ画面に映したりする際には少し扱いにくく感じることがあります。本ガイドでは、YouTubeショートの技術的な仕組みをはじめ、目的に応じたファイル形式の選び方、スマートフォンやパソコンでリンクをコピーする手順、確保しておくべきストレージ容量の目安、さらには大画面テレビでの再生や動画編集ソフトでの活用方法まで詳しく解説します。

あわせて、最も重要なポイントである「誰の動画を保存するのか」という権利面についても取り上げます。自分が制作した動画や、保存の許諾を得ている素材であればオフラインコピーを作成しても問題ありませんが、他人が制作した作品を無断で収集・再投稿することは認められていません。以下の各セクションでは、この線引きを常に踏まえながら解説していきます。

YouTubeショートとは何か

YouTubeショートとは、縦長または正方形の画面サイズでアップロードされ、YouTubeが定める最大尺の範囲内に収まる通常のYouTube動画のことです。この最大尺はこれまで何度か見直されており、当初は60秒まででしたが、のちに最大3分まで延長されました。そのため「ショート」という枠組みの中でも、数秒の短いクリップから比較的長めの動画まで混在しています。ご自身で公開する動画のために正確な上限を確認したい場合は、YouTubeの最新のヘルプページを参照してください。

標準的なアスペクト比は9:16で、横9に対して縦16の比率になっています。スマートフォンでは画面いっぱいに表示されます。正方形（1:1）や4:5の動画にも対応していますが、ショートフィード自体は9:16を前提に設計されています。なお、ショート動画は特別な独自形式のファイルというわけではありません。内部的には他の通常動画と同じ映像・音声ストリームの仕組みで配信されているため、同じファイル形式や変換オプションがそのまま適用できます。

主な解像度

ショート動画の大半はスマートフォンで撮影されるため、一般的な解像度もスマホカメラの仕様に沿っています。実際に取得できる解像度は、制作者がどの画質でアップロードしたか、またYouTubeがその動画に対してどの解像度を提供しているかによって異なるため、以下の数値は保証値ではなく一般的な目安として参考にしてください。

表記画面サイズ（縦向き）主な用途1分あたりの容量目安*
360p360 x 640非常に小さい画面、低速な回線環境約3〜6 MB
720p720 x 1280スマートフォンでの日常的な視聴約10〜20 MB
1080p1080 x 1920スマホ・タブレットでの高精細な視聴、簡単な編集約20〜45 MB
それ以上1080 x 1920超元の動画が対応している場合のみ条件により大きく変動

*容量はあくまで目安であり、映像の動きの激しさやコーデック、ビットレートによって変わります。たとえば動きの少ないトーク動画は、展開の速いスポーツ映像よりもはるかに効率よく圧縮されます。解像度とファイルサイズのバランスについてさらに詳しく知りたい場合は、動画解像度ガイドをご覧ください。

保存する前に確認すべき権利と許諾

無料で視聴できるショート動画であっても、自由に保存・複製・再公開してよいわけではありません。制作者が別段の指定をしていない限り著作権は制作者に帰属し、YouTubeの利用規約でもコンテンツへのアクセス方法に制限が設けられています。入力したリンクを変換するツールを使っても、これらの権利関係や規約が変わることはありません。ツールを適法に利用する責任は、常に利用者自身にあります。

ショート動画をオフライン保存するのは、原則として次のような場合に限定するのが妥当です。

  • 自分がアップロードした動画のバックアップを取りたい場合や、編集用のコピーが必要な場合。
  • Creative Commonsライセンスの下で公開されているか、パブリックドメインに属しており、クレジット表記などのライセンス条件を遵守する場合。
  • 制作者本人から、想定している利用目的について明確な許諾（書面やメッセージなど記録に残る形が望ましい）を得ている場合。
  • お住まいの地域の法律で私的使用のための複製が認められており、かつ有料・レンタル・保護された配信・ライブ配信・非公開動画のいずれにも該当しない場合。

有料またはレンタルのコンテンツ、保護されたストリーム、ライブ配信、非公開動画は保存しないでください。また、他人のショート動画を自分の作品のように再アップロードすることも厳禁です。フェアユースや各種ライセンスの考え方、それぞれで許可される範囲について詳しく知りたい方は、YouTubeの著作権・フェアユース・Creative Commonsガイドをご参照ください。当サイトにおける権利関連の対応方針については、DMCAポリシーでもご確認いただけます。

MP4とMP3：目的に合った形式の選び方

どのファイル形式が適しているかは、保存したクリップをその後どう活用するかによって決まります。ショート動画の多くは映像が主役ですが、音声によるワンポイント解説やボイスメモ、自作の楽曲など、背景映像よりも音声が本質であるケースもあります。

形式含まれるデータ適した用途注意点
MP4（動画）映像と音声を1つのファイルに収録オフライン視聴、自作動画の共有、動画編集ファイルサイズが大きくなる
MP3（音声）音声のみ自分のトーク音声や自作音源の聴き返し、音声トラックの確認映像は一切含まれない

特別な理由がなければ、MP4を選ぶのが確実です。追加のソフトを入れなくても、ほとんどのスマートフォン、パソコン、タブレット、テレビでそのまま再生できます。MP3は音声だけが必要な場合に限って選択してください。なお、ショート動画の音声は尺が短いだけでなく配信時点で既に圧縮されていることが多いため、高いMP3ビットレートで変換しても、元データに存在しない音のディテールが蘇るわけではありません。ビットレートの違いが音質や容量にどう影響するのかについてはMP3ビットレート解説記事で分かりやすく説明しています。また、MP4とWebM、MKV、M4Aの違いを比較したい場合はメディア形式比較ガイドもあわせてご覧ください。

スマホ・PCでショート動画のリンクをコピーする方法

変換作業は、対象となる動画のURLを取得するところから始まります。YouTubeショートのリンクは「youtube.com/shorts/」のあとに11文字の動画IDが続く形式です。利用環境ごとのコピー手順は以下のとおりです。

YouTubeモバイルアプリの場合

  1. 対象となるショート動画（自分の動画や利用許諾を得た動画）を開きます。
  2. 画面右側に表示されている「共有」アイコンをタップします。
  3. 共有メニューから「リンクをコピー」を選択します。
  4. スマートフォンのブラウザで変換ツールを開き、入力欄にリンクを貼り付けます。

モバイルブラウザの場合

  1. ブラウザ上で対象のショート動画を開きます。
  2. アドレスバーをタップし、URL全体を選択します。
  3. 「コピー」を選び、変換ツールのページに貼り付けます。

パソコン（デスクトップ・ノートPC）の場合

  1. ブラウザで対象のショート動画を開きます。アドレスバーのURLには「/shorts/」が含まれています。
  2. アドレスバーをクリックし、Ctrl+A（Macの場合はCmd+A）で全選択してから、Ctrl+C（Macの場合はCmd+C）でコピーします。
  3. あるいは、動画の右側や下部にある「共有」をクリックして「コピー」を選ぶこともできます。
  4. コピーしたリンクをツールに貼り付けます。

ブラウザでは開けるのに変換ツールでリンクが認識されない場合は、URLが途中で切れていないか、前後に余計な文字が混ざっていないかを確認してください。非公開動画、年齢制限付き動画、ライブ配信のリンクには対応していませんが、これは仕様どおりの動作です。スマートフォンでの操作に特化した手順は、iPhone・Android向けガイドでステップごとに解説しています。

ストレージ管理とファイル整理のコツ

ショート動画は1本あたりは小さく見えても、数が増えると意外と容量を圧迫します。たとえば平均30秒の1080p動画を200本保存したフォルダは、映像の動きやビットレートにもよりますが、おおよそ1.5〜3 GBに達します。ノートパソコンなら余裕のある容量でも、空き容量の限られたスマートフォンでは無視できない負担になります。

  • スマートフォンでの視聴のみが目的であれば、720pを選ぶのがおすすめです。小さい画面でも十分きれいに見え、容量も大幅に節約できます。
  • 1080pは、後から編集する可能性がある自分の動画に限り、かつ元ソースが対応している場合だけ残すようにしましょう。
  • 「2026-05-12_テーマ_制作者名.mp4」のように一貫した命名規則を使うと、目的のファイルを探しやすくなり、出典も一目で思い出せます。
  • 自分の作品ではないファイルを保存する場合は、制作者名・元のリンク・許諾内容やライセンス情報を記した簡単なテキストメモを同じフォルダに置いておくと安心です。
  • 自分で制作した動画は別のドライブやクラウドフォルダにもバックアップを取り、不要になった一時コピーはこまめに削除しましょう。

自身のアップロード動画を体系的にアーカイブしたいクリエイターの方は、自分のYouTube動画をオフラインでバックアップする方法も参考にしてください。保存の権利がある講義動画を使って学習用ライブラリを整理する方法も紹介しています。

縦型動画をテレビで視聴する方法

9:16の縦型動画を16:9のテレビ画面で再生すると、映像が画面横幅のおよそ3分の1しか使わないため、左右に広い黒い帯が表示されます。これはファイルの不具合ではなく正常な表示です。テレビで縦型動画を見るときは、いくつか現実的な方法があります。

  • 左右の黒帯をそのまま受け入れる。自分の動画を家族で手軽に観る程度であれば、これが最も簡単な方法です。ほとんどのテレビやストリーミング端末のメディアプレーヤーは、映像を中央に配置して再生してくれます。
  • スマートフォンからキャストする。キャスト機能や画面ミラーリングを使えば、スマートフォン上での表示そのままに縦型動画を映し出せます。見え方は同じく左右に黒帯が入る形になります。
  • 背景をぼかした横長版を作る。動画編集ソフトを使い、元の縦型映像を拡大してぼかしたレイヤーを背面に敷き、その中央に本来の映像を重ねて画面全体を満たす手法です。ただし、この加工は自分の撮影素材、または改変の許諾がある素材にのみ行ってください。
  • ディスプレイを縦向きに回転させる。ピボット機能付きのパソコン用モニターであれば画面を縦向きに回転でき、縦型動画を画面いっぱいに快適に視聴できます。

対応しているファイル形式はテレビの機種によって異なります。うまく再生できない場合は、映像コーデックにH.264、音声コーデックにAACを採用したMP4が最も互換性の高い組み合わせです。FAT32またはexFAT形式でフォーマットしたUSBメモリにファイルをコピーして再生するか、HDMI接続したパソコンから出力する方法も有効です。

動画編集ソフトでショート動画を活用する

複数の自作ショート動画を1本のまとめ動画に編集したり、横長動画用に再構成したりする場合は、最初にプロジェクト設定を正しく整えておくとスムーズに進められます。

  • 縦型のまま書き出す場合は、プロジェクトを1080 x 1920、フレームレート30 fps（または元動画のフレームレートに合わせた設定）で作成します。
  • テレビや通常のYouTube動画向けに横長で出力する場合は、1920 x 1080のプロジェクトを作成し、その中に縦型クリップを配置してサイズや位置を調整します。
  • 映像の引き伸ばしは避けてください。9:16のクリップをトリミングせずに16:9の枠へ無理やり広げると、人物の顔や文字が不自然に歪んでしまいます。
  • スマートフォンのアプリ画面では下部や右端に操作ボタンや説明文が重なるため、タイトルやテロップは中央のセーフエリア内に収めるようにします。
  • 再アップロード時の互換性を確保するため、書き出し形式にはH.264コーデックのMP4を選択してください。

編集プロジェクトにBGMや効果音を入れる際は、自分の用途で問題なく使える権利クリア済みの音源を選びましょう。探し方やクレジットの記録方法については、YouTubeでCreative Commonsやロイヤリティフリーの音楽を探す方法で解説しています。

共有時に制作者のクレジットを明記する

トラブルの多くは「共有」の場面で発生します。自分の動画であれば自由に共有できますが、他人の動画を紹介したい場合は、ファイル自体を送るよりもURLリンクを共有する方がほとんどの場合において適切です。リンク経由であれば再生数や評価が正当に制作者へ届き、制作者が後から動画を修正・削除する権利も守られます。

制作者から許諾を得ている場合や、再利用が認められたライセンス素材を扱う場合は、次のマナーを徹底しましょう。

  • 制作者名を明記し、元のYouTubeショートへのリンクを添えます。
  • CC BYなどのライセンス種別を記載し、ライセンス条項で求められる場合はバージョンも明記します。
  • 制作者を識別できる名前、ハンドル名、キャプションなどをトリミングで切り落とさないでください。
  • 他人のクリップを自作のように見せかけたり、許諾のない作品を別のチャンネルやプラットフォームへ再アップロードしたりしてはいけません。
  • 制作者からコピーの削除を求められた場合は、速やかに応じてください。

正確性と責任ある利用に対する当サイトの姿勢は編集方針にまとめています。また、本シリーズの他の解説記事はブログ一覧からご覧いただけます。

よくある質問

YouTubeショートは最長でどのくらいの長さになりますか？

YouTubeショートは当初60秒まででしたが、現在は最大3分までの動画に対応しています。プラットフォームの仕様は変更されることがあるため、具体的な企画や制作を始める前にYouTube公式ヘルプで最新の上限を確認することをおすすめします。

ショート動画に適したアスペクト比は何ですか？

9:16（一般的には1080 x 1920ピクセル）を使用してください。正方形や4:5の動画もフィードに表示されますが、縦型の9:16が画面全体を満たす形式であり、ショートフィードの設計基準となっています。

ショート動画はMP4とMP3のどちらで保存すべきですか？

映像と音声をセットで保存したい場合はMP4を選んでください。通常の再生にも編集にも最適です。MP3は、自分のトーク音声や自作音楽など音声データだけが必要な場合に限定して使いましょう。MP3には映像情報は含まれません。

見つけたショート動画ならどれでも保存してよいのですか？

いいえ、それはできません。保存してよいのは、自分が制作したショート動画、Creative Commonsライセンスやパブリックドメインの素材、または明確な許諾を得たコンテンツに限られます。著作権とYouTubeの利用規約を尊重し、他人の作品を無断で再アップロードすることは決して行わないでください。

縦型動画をテレビで再生すると左右に黒い帯が出るのはなぜですか？

9:16の映像は16:9のテレビ画面に比べて横幅がはるかに狭いため、映像のない左右の余白が黒く表示されます。ファイルが破損しているわけではありません。スマートフォンからキャストする、黒帯をそのままにして視聴する、あるいは編集ソフトで背景ぼかし版を作成するといった方法で対応できます。
